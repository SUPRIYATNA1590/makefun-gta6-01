Solmar Heat is an open-world crime game in the spirit of GTA 6, built with three.js: a sun-soaked original city (Solmar City) to explore on foot and by car, with street traffic, sidewalk pedestrians, cars to steal and drive, a 5-star wanted level with police chases, six story missions, combat with pistol and shotgun, a HUD with a live minimap, a start screen and localStorage saves — all running offline from static files, with synthesized WebAudio sound and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to play. WASD to move/drive, mouse to look and aim, E to enter a car, F to interact.
